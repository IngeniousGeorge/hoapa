The formal home of the praxis nexus: the type-diagnosis graph dynamics modelled as a category enriched in a quantale / *-autonomous base, together with its Cauchy / reflexive (Isbell) completion. In this setting "openness" — treating the foreign as one's own — is exactly reflexive completeness, which coincides with representability, which is what [legitimacy-representability] reads as legitimacy. It supplies the ambient structure the [praxis-nexus] members share, and is built over the conserved base [risk-linear-base]. See `workflow/arc/14_trust_and_legitimacy_as_enrichment.md`.
