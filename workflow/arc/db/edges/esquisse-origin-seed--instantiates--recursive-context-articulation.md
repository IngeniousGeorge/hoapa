The project's own genesis is an instance of its central pattern: Grothendieck's late corpus is a context, the reading of it into three pillars is the multiplicity, and this framework is the new language-type that stabilises — after which the framework becomes a new context in its own right. So Hoapa's founding is itself a case of context → multiplicity → language-type → new context, which is the sharpest possible demonstration that the framework is an instance of itself rather than a description imposed from outside.
