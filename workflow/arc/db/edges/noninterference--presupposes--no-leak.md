An individualised member edge: noninterference presupposes no-leak because "identity labels cannot affect acceptance" is only enforceable if identity does not leak across the boundary in the first place. Noninterference is, in effect, [no-leak] lifted from the boundary to the whole acceptance procedure, so it inherits the same theorem as its semantic core rather than restating it as a policy.
