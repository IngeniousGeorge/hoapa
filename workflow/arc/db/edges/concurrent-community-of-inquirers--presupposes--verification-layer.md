The community's anti-managerial character presupposes a mechanised verification layer: the move from "trust the checker" to "run the checker" is what removes the privileged human verifier without leaving a gap, so that authority over formal claims need never be personal. Remove the layer and checking falls back to status, reintroducing exactly the managerial class the design exists to dissolve; the layer is therefore not an add-on but a condition of the community's core claim.
