# Pedagogy track

Held-loose side track: `pedagogy/` companions for each `agda/` file, walking code chunk by chunk with the audience presumed to be a working mathematician new to the formalism (not a working type-theorist new to the math).

## Mirror pattern

`pedagogy/<Track>/<File>.md` mirrors `agda/<Track>/<File>.agda`. Each companion:

- walks the file in source order, chunk by chunk;
- treats references as block-quoted citations alongside the code, not footnotes;
- uses the console-metaphor template established in `pedagogy/ModalHoTT/Modalities/Cohesion.md`.
