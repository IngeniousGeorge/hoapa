The spine of the whole construction: the two legs are not sequenced — neither is
"first" — but co-arise as an adjoint pair, the project name for which is Allow ⊣
Require (see [cross-site-adjunction]). The left adjoint unfolds modal-HoTT
perspectives into a running unityped community; the right adjoint reflects the
community's operational separation back into perspectival type theory. This is a
load-bearing cycle: read either way, each leg presupposes the other, which is
exactly why the dependency graph has no single root at this point — the harmony here
is a mutual dependence, not a foundation.
