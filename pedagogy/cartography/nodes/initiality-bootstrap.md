The framework's answer to "where does it start", given that it forbids a first
instant or a foundational floor: it starts from a *fixed point* rather than a ground —
secure bases are "produced, not given", via initiality / free-model (initial-algebra)
universal properties that let a context bootstrap its own secure structure. This is
the surprising temporal inversion: the nearest thing to an entry point is a
self-stabilising fixed point of [recursive-context-articulation], not a base on which
the rest is built. See `workflow/arc/11_reality.md` and the free ⊣ forgetful avatar of
[cross-site-adjunction].
