An internal region edge: collective memory presupposes provenance, because remembering that a claim was rejected, repaired, or superseded requires its lineage to be intact and inspectable. [provenance] guarantees the finite dependency path back to each claim's ancestry; collective memory then attaches status along that path so future reuse must carry it. Without provenance the system could forget a claim's fate; with it, the trace becomes an institution that does not silently relitigate settled errors.
